# Workshop 2 相机交付流程发布

2026-10-15 已发布到 [RDK Studio 插件中心](https://rdkstudio.d-robotics.cc/rdkstudio/?tab=plugins#/plugins)。从相机原生工作区进入“交付与验收”，可以定义场景、光照、必需指标及阈值，显式选择交付版本、记录实际观察和报告、下载精确候选 JSON 与实验调优手册。

本次补齐厂商候选原字节归档、显式角色加载回执、参数/场景/图像绑定、计划版本隔离、原始参数恢复栅栏与 `delivery.json`。SDK 会话快照继续标注会话恢复用途；操作员记录达标、SDK 回读成功与独立画质认证分别呈现。缺少厂商字段绑定时阻止生成，不宣称已有可部署效果库。

Studio 插件为 1.2.1，平台完整包为 1.1.3，下载包包含 source-only 板端 SDK 归档及接入说明。SDK 文件上限 16 MiB；仅 tuning_load/MCP JSON 入口 24 MiB，其他入口保留宿主配置。代码未自动安装到板卡。

## 验证

正式候选在实际 Node 22.16.0 与 22.19.0 下分别通过平台 59 项、Studio 44 项，以及成对账号桥 HTTP→Python/NumPy 2.0.2 BLC→ZIP 字节校验、两种插件精确字节下载。源码与私有 SDK 测试包含 Python 127 项、HTTP 14 项、三组 native shim。完整壳的中英桌面/窄屏、账号晚到响应、焦点及 JSON/Markdown 下载使用隔离 UI fixture 验证。

上线后的 30 项检查通过：current/实际 PID cwd/Node、payload/继承基线哈希、私有桥配置、健康/ready、新版 HTML/资源和未登录拒绝。全新匿名浏览器加载 24 个新版资源，页面错误与服务端错误均为 0。真实生产 SSO 完整业务流程未验收。

测试曾因旧线上 SSO 导入的 60 秒维护 interval 保活而超时。最终测试仅清理路径、SHA、调用栈和 delay 精确匹配的隔离维护 timer，未知 timer 不清理；完整测试自然结束，无强制退出，生产 SSO 未修改。

## 范围与待验收

本轮没有连接相机、执行板端写入或验证新候选在目标板的实际加载及画质；历史采图记录不能替代本轮候选验收。225 分钟议程、交付手册与软件流程已准备，现场可达标仍需实际板卡、模组、SDK 与光照场景演练。

共享源码的整仓快速门禁仍受 RDK Docs 0.1.6/0.3.0 依赖差异及并发源码证明影响。本次以真实线上基线叠加相机白名单产物，没有发布该依赖升级或其他会话改动。

上一版本、精确 manifest 和控制器私有回滚备份均保留；本次没有为测试而执行生产回滚。机器可核查摘要见 [发布证据](2026-10-15-camera-workshop2-delivery.json)，现场步骤见 [Workshop 2 调优手册](../vision-workshop-workshop2.md)。
