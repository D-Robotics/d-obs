## 真实性与范围

来源标签及目标 ID 是纳管声明；真实文件 SHA-256 与字节数可核验，不代表硬件已连接。外部 URI 只登记位置，平台不获取远程内容。改善验收按归档证据关联的申报指标与固定阈值计算，明确 `measurementSource: reported`，不冒充自动设备测量。

线上视觉模型已启用，但本轮实际 capabilities 中已配置设备适配器数为 0，capture/apply unavailable。因此没有执行或宣称真机采集、参数应用和物理效果验证。数据中心提供下载客户端用于实际云端/终端上传；训练、设备采集和下发可接专业系统的实际产物与回执，当前没有自动训练或任意设备执行。

备份副本主动撤销所有采集 token，线上凭据不变；恢复后开放任务重新签发，旧备份不能复活已撤销凭据。公开资产 manifest 不含原始文件和 token，不能独立用于恢复。

## 本轮修复的关键缺陷

- 保留 Buffer 类型并测试真实上传/下载完全一致，避免 Express JSON 化下载。
- 并发上传额度覆盖归档处理，客户端断连不会提前释放已开始的业务额度。
- 清单丢失时 fail-closed 并保留文件，初始化先保存空清单，禁止误删真实资产。
- 读取状态时重算阶段和数值判定，推进前复核全部历史文件完整性。
- 验收文件独立于基线和之前阶段的 ID 与内容哈希；部署证据不等同验收通过。
- 数据集上限统一为 300，覆盖合法视觉实验的全部制品快照。
- 修复 textarea 原生只读属性、主按钮悬停对比、旧身份缓存及迟到响应，权限失效归并为单一登录入口。
