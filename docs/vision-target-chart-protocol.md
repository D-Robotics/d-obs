# d-obs 目标卡 v1 · 制作与拍摄评估协议

目标：给相机点亮与 ISP 调优一个**可测量的客观目标**，让「AI 调参是否有效」从主观描述变为可量化、可复验的数值对比（ΔE 从 X 降到 Y）。参考色值由 `server/monitoring/vision-workshop-quality.ts` 单源定义，资产由 `tools/generate-vision-target-chart.mts` 生成，可随时重建并核对哈希。

## 1. 卡片资产

- 文件：`docs/assets/vision-target-chart-v1.png`（1560×260，上排 12 灰阶、下排 12 彩色，共 24 色块，无文字标记）。
- SHA-256：`89f2a4a1d01cb7fa5f31dbe12e1c01d5af8c8dc11e19f79b284a988738bdbe11`。
- 重建：`node --import tsx tools/generate-vision-target-chart.mts`（确定性输出，哈希一致）。
- 参考值即像素值：灰阶 0→255 共 12 级；彩色含三原色/青品黄/橙紫/肤色近似/植物绿/深蓝/暖白。

## 2. 制作方式（二选一）

| 方式 | 做法 | 注意 |
| --- | --- | --- |
| 屏显（推荐入门） | 图片查看器全屏显示，关闭夜间模式/护眼/色彩增强，亮度固定后不再调整 | 屏幕 gamut 与 sRGB 的偏差会计入 ΔE；同一屏幕前后对比成立，跨设备对比不成立 |
| 打印 | 按原始像素尺寸打印（不缩放、适应纸张居中），哑光纸优先 | 打印色彩管理不可控；同一张打印件前后对比成立 |

**关键纪律：评估「调参前后」必须使用同一介质、同一亮度/同一张打印件。** 本方案证明的是相对改善，不是绝对色彩正确。

## 3. 照明（可调照明规程）

1. 基线照明：均匀漫射光（避免点光源直射卡面产生眩光/反光），记录光源类型、色温（K）、照度（lux，有照度计则记，无则注明「未测」）。
2. 可调验证：至少三档条件各拍一组——①基线档；②降约一半照度档；③（可调色温时）偏暖/偏冷档。每档内完成「基线参数 → AI 调参 → 恢复」的完整对照。
3. 每次拍摄记录当时档位；不同档位的结果不得混合比较。

## 4. 构图与拍摄

1. 目标卡**满幅**：卡片边缘充满整个画面（当前引擎假定卡片满幅且正对，无自动定位；构图偏差直接进入误差）。
2. 相机正对卡面，避免透视倾斜；卡面无阴影、无反光斑。
3. 拍摄前固定或记录：曝光模式、曝光时间、增益、白平衡模式。AI 调参前后除目标参数外不得改动其他设置。
4. 使用平台「相机采图 → 保存当前画面」或导入流程归档，场景字段填写照明档位（如「基线 5000K・约400lux」）。

## 5. 平台内评估

1. 工作台「启动与预览」步骤 →「相机实际画面留样」卡 →「按测试卡评估」。
2. 输出：色块平均 ΔE76 / 最大 ΔE76 / 灰阶最大 L 偏差 / 白平衡偏移 a*/b*，展开可看逐色块参考 vs 实测。
3. 判读口径：
   - **调参有效** = 同一照明档位下，平均 ΔE76 与灰阶偏差同步下降，且白平衡偏移向 0 收敛；
   - 单一色块改善但其余劣化，以平均值为准并如实记录；
   - ΔE 上升但主观观感「更好」，按纪律记为「未通过客观判据」，不签收。

## 6. 已知局限（页面同步展示）

- 参考值为 sRGB 定义值，屏显/打印介质未经光谱校准，ΔE 含显示与拍摄路径的全部偏差；
- ΔE76 为 Lab 欧氏距离，非感知精确度量（后续可升级 CIEDE2000）；
- 无自动定位，依赖构图纪律；不构成画质总分，正式验收仍需人工签收。

## 7. 与 RAW 闭合的关系

同 RAW 前后对比（唯一科学上完全成立的证据形式）仍被 Bayer RAW 独立回读资格阻塞（见 `docs/workshop2-raw-sdk-qualification-blocker.md`）。目标卡方案的价值在于：**在 RAW 缺口闭合前，先用受控目标建立可量化的相对改善证据链**；RAW 闭合后两者叠加使用。
