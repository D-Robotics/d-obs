## 操作流程

1. 登录，创建或选择实验，绑定实际登记的相机，核对板型、相机模式和 SDK。
2. 探测、检查链路、启动已有驱动并预览；新 Sensor 驱动和设备树自动生成尚未提供。
3. 保存原始配置与恢复基线，再采集视频帧或 Bayer RAW。两种素材分别记录。
4. AI 基于实际图像、控制回读和历史选择调整、保留、恢复或停止；改参后核对回读和新帧。恢复未确认时先显式恢复，再开始新调试。
5. 在匹配 SDK 条件下读取、加载和导出效果库。离线标定使用已记录采集条件与哈希的素材，执行 BLC/LSC/CCM/AWB，先看应用计划再按可信 SDK 映射应用。
6. 保存工程师实际评价，下载参数、标准实验包和操作手册；标定结果通过任务结果接口另行读取。计算完成不自动代表上板生效或画质通过。
