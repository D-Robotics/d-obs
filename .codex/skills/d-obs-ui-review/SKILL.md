# d-obs 可观测平台 UI 审查

把操作员的判断与行动放在首层，把低频配置和完整数据按需展开；减少重复入口和说明。
本技能只支持当前授权的审查、代码修改和本地验证，不授权部署、外部写入或发布。
以下源码路径和命令均相对真实 d-obs 仓库根目录。

## 先确定真实实现

1. 核对产品与仓库：查找 `package.json` 的 `rdk-d-obs` 与 `server/monitoring/observability-page.ts`；不要因当前目录是 RDK 学习平台而改错产品。
2. 先读仓库指令与 `git status`、目标文件 diff；保留并发 WIP。同文件交错时限定自己的区域，不回退别人新增的真实导航壳或模块。
3. 读页面 HTML、导入与脚本拼接顺序，再查相邻 renderer；不要优化未挂载的旧 CSS 或死模块。
4. 从实际 `.nav-main`、`.nav-group` 和 `data-view` 建立入口清单；保留现有主任务与所有旧深链，再决定减少哪些重复表达。

## 详情空间利用率与 CSS 覆盖

- 在真实浏览器读取详情的 `getBoundingClientRect()` 与 computed `position/width/gridTemplateRows`，再对照页面 style 拼接顺序；源码的 `.trace-detail{position:fixed}` 可能被后加载的 `.ops-observability .panel{position:relative}` 覆盖，只留下 720px 宽度和旧 inset。
- 用共享详情 ID 明确重置定位、inset、width 与 max-height，同时验证运行列表和会话列表的两种挂载位置；不要只给 `.trace-workspace` 子节点修样式。
- 完整、无 span、候选片段与读取失败都走真实 renderer。纯 CSS 分栏识别瀑布可用 `.trace-detail-section:not(:has(.trace-evidence-sources))`；不要依赖 `.trace-waterfall`，无 span 时不存在该节点。
- 固定高度且可滚动的 grid 用内容行高保护长上下文；`auto ... 1fr` 会在容器高度不足时压缩 `overflow:hidden` 的上下文行，使后续证据重叠。实际验收过的组合是顶部/上下文 `max-content`、证据 `minmax(max-content,1fr)`，移动单列用 `grid-auto-rows:max-content`。比较各区块的 y/height，确认没有交叠后再截图。
- 窄栏的引用、摘要与属性值允许 `overflow-wrap:anywhere`；亮暗主题中的事实/上下文值使用 `var(--text)`、安全属性摘要使用 `var(--muted)`，不要假设旧编号色值在暗色中仍有可读对比度。
- 独立快照建好后不要重新复制整个正在并发修改的文件。后续只同步自己的 patch；若新增未验收 import 混入快照，重建原始文件加自己的 patch，保留共享工作区，避免用补拷新依赖的方式扩大此次发布范围。
- 列表密度通过同数据、同视口的真实 renderer 比较：记录首行 y、各行高度和完整可见条数；覆盖状态与工具可并排，但错误、缺失片段、无安全定位信息与分页失败仍在首层。若隐藏重复 hero，确认运行/会话切换和至少一个“低敏 · 账号隔离”提示仍可见。
- 除 720/721 断点外，列表改为单列时也检查 1100/1101；顶部时间窗口和操作区可能比列表更先溢出，必要时只在当前视图让 `.page-head-actions/.page-head-controls` 换行，不缩小或丢弃操作入口。

## 简化任务与数据

- 主导航表达高频任务；低频入口进入按需目录，页面子模块使用短标签，帮助由用户主动打开。
- 一个页面保留一个主标题；删重复 breadcrumb、intro、展开摘要和通用教程，保留影响判断所需的数据口径。
- 复杂图表、配置表单、历史和审计可渐进展开；进行中异常、数据未知或过期、审批待办及加载失败在摘要中可见。
- 区分没有异常与无法取得数据；503、未授权、中心库未启用及样本不足不能变成零告警或绿色健康。
- 候选展示待审状态与证据，不暗示已发布；事故和待审徽章在新快照归零时清空，缺失快照保持未确认语义。
- 刷新保留各独立图表的系列、时间范围及 disclosure 选择；总览与 Trace 的共享窗口遵循已有绑定，避免覆盖其他图表状态。

## Trace 入口去重

- 先区分查看维度与外部工具：运行证据链和会话 Trace 是同一数据的“按运行 / 按会话”视图；Agent Trace 若只是 Langfuse 看板，放入已配置时才显示的可选详情入口，不保留第三个平级模块。两个视图复用运行详情与权限边界。
- 线上没有会话 API、已加载运行却有匿名 `sessionRef` 时，可在相同范围内按该字段投影已加载样本，按 `runRef` 去重。明确这是当前样本的会话分组及未关联会话的运行数量；不虚构会话、不暗示已加载完整会话，也不为入口合并扩大后端发布。
- 模式共用环境、时间窗口、查询、结果筛选与租户；顶部刷新和继续加载沿用当前范围，并拒绝不同环境或身份的分页响应。模式切换不能默默查回生产环境或丢失管理员租户选择。
- 异步成功与失败分支均先核对账号、租户、范围和请求是否仍有效，再移除权限屏或更新结果与错误；迟到的刷新及分页不能覆盖切换身份后的拒绝访问状态。
- 重建列表前记录模式按钮、筛选、搜索与环境选择的焦点，搜索同时保留选区，展开的会话保持展开。原生 `disabled` 会在请求期间丢失键盘焦点；用 `aria-disabled` 配合加载防重入守卫时，实际验证等待中和完成后焦点以及重复触发行为。
- 共享详情的内存引用重置后，隐藏视图中的 DOM 节点可能仍存在；找回并重新登记既有占位节点，跨 scope 新建前移除旧节点。回归实际“会话详情 → 关闭 → 空环境 → 按运行”以及身份重置往返，断言详情 ID 始终唯一、环境重读后模式按钮焦点仍在。

## 保持交互边界

- 保留 `resolveViewRequest` 别名、`#alert=`、`#remediate=` 和子路由；新增导航层使用父级映射，不改数据访问范围。
- 同步检查父级 active、`aria-current`、当前 domain、徽章和候选提示；子路由不能失去所属任务高亮。
- 主导航、目录和搜索遵循当前管理员、组员、租户 token 可见面；界面裁剪与 `setView` 权限守卫都保留。
- 搜索默认仅呈现常用入口，输入后查低频模块；异步实体结果绑定账号、租户、角色和请求，旧结果不能串入新身份或新查询。
- 折叠菜单处理外部点击、Escape、焦点恢复和 resize；移动端复用已有节点与监听，往返断点后仍只有一套导航。
- 页面子模块收进“更多”时移动原有标签节点，保留 ID、监听与深链；把当前深链模块提升到可见栏。方向键过滤关闭的祖先 details，不能只检查标签自身 hidden。相同路由的后台 `loadAll → setView` 保留展开菜单与内部焦点，只有实际换路由才关闭。
- 免登录的 `setView` 可能先于 `/auth/me → applyAuthMode` 执行，允许的成员深链不会再触发 `setView`。子菜单在身份解析之后也要同步角色可见面；沿用真实 `applyAuthMode` 的返回与副作用，不依赖再次切页。用“初始平台视角 → 异步成员身份”的真实函数反例验证，不只在 fixture 初始化时设置角色。
- 角色裁剪使用自己的隐藏 class，不移除其他模块已有的 `hidden`。空“更多”设置原生 `hidden` 后，核对 computed display；现有 details 样式可能覆盖浏览器默认隐藏规则，需要当前呈现层的 `[hidden]{display:none!important}`。
- 移动导航脚本有独立 `MOBILE_PRIMARY` 列表。只改变桌面 DOM 不会同步手机入口；核对实际线上列表，限定唯一已知常量替换并保持其余脚本原字节，未知或多处匹配拒绝组装。往返 720/721 后验证原节点、监听和实际入口数，数量从本次基线读取。
- 把选中的低频子标签提升到查询栏后，用实际 390px 深链验证额外标签不会撑宽页面。根视图 grid 的自动列有 intrinsic minimum，单改 flex-wrap 仍可能溢出；需要时对单列根视图使用 `minmax(0,1fr)`，移动标签允许换行，宽日志表在自己的容器内横向滚动。分别核对根 scrollWidth、菜单边界和表格滚动，不用 overflow:hidden 丢弃数据。

## 对话正文组件与详情状态

- 中文正文用保留换行的阅读排版，工具参数和结果按需展开；把复制、来源等操作放在正文之后，避免短消息被操作区撑高。
- JSON 解析只用于合法性验证，显示缩进保留原 token，验证大整数、重复键、键顺序和转义；设置深度与格式化长度上限，超限明确回退原文。
- 原文复制与格式化视图分离；长文预览仅限制显示，完整已返回内容仍可查看/复制，不能把阅读折叠当作服务端截断。
- 复制进行中使用可访问的禁用状态和防重入守卫，避免原生 disabled 使键盘焦点跳到 body；完成时不抢走用户已移开的焦点。
- 给对话汇总与单 span 正文不同的稳定 disclosure/focus/scroll key。只在相同账号、租户与运行内恢复状态；真实轮询、会话重新加载和旧异步请求均需反例。
- 将原文和来源合并到外层 disclosure 后，内层 raw/source 的 toggle 不应强制展开父层；状态恢复也会触发原生 toggle。验证“内层开、外层闭”经过实际详情刷新仍保持外层关闭，且焦点留在当前控件。只有明确的初始 `showSource` 选项可以打开父层。
- 固定详情面板遮挡列表时，检查首控件 Shift+Tab 是否落入被遮挡的行。采用与外部导航行为一致的对话框语义，过滤隐藏、折叠和禁用控件，支持 Tab 首末循环与 Escape 返回原入口；非模态面板不能宣称 aria-modal=true。
- 检查顶部刷新是否实际重读会话接口，而不是仅更新总览。mock 测试观察请求调用，CUA 核对展开与返回焦点；不以文字更新代替请求证据。
- 指定 Run 搜索的刷新反例必须走实际 `loadAll → setView → refreshTraceSearch`，不能只替换 overview 引用。总览轮询沿用当前 Run 筛选，取消在途请求时保留已确认的搜索标记；身份、租户或时间窗口改变仍清理旧状态。验证迟到的旧搜索响应不会覆盖新搜索。

## 业务看板与查询编辑器

- 从实际挂载的 `observability-page-board-editor.ts`、看板 HTML 与最终 CSS 拼接审查；先区分查看和编辑，首层呈现当前看板、访问范围、面板数与查询状态，变量筛选提供恢复已保存默认值的操作，重置筛选不写回看板。
- 刷新仅在相同账号、租户、看板和面板定义内复用卡片与变量控件；保留焦点、文本选区和展开菜单。重新 GET 同 ID 会创建新 record，复用节点的操作需解析当前 record，测试二次 GET 后编辑和复制确实修改新对象。
- 保留图表时明确标记“更新中 / 上次查询结果”；502/503 不显示成当前结果或零数据。401/403 清理整个访问范围中的旧图与记录，使其他在途查询及旧 GET 无法恢复已拒绝的数据，重试必须重新取得授权的看板定义。
- 查询请求同时绑定身份、当前看板、面板定义、变量和时间范围。文本变量使用短防抖，输入当下即标记旧图过期并失效前一请求；验证迟到响应不会覆盖新筛选，另一个面板成功不会清除失败摘要。
- 面板编辑留直接入口，复制、存库和删除收进原生 details；保留完整查询、变量、单位、归约和阈值，Escape 返回 summary。共享查看者不能编辑、拖拽或保存，复制生成私有看板；48 个面板边界同时覆盖 API、直接复制和已打开的编辑器。
- 查询对话框的标题、错误与保存操作独立于滚动区；中间 flex 子项使用 `min-height:0`，预览 sticky 绑定实际滚动区。展示设置和库面板默认折叠，焦点循环包含 summary、排除关闭 disclosure 的内容；移动单列仍能看到保存与错误。
- 初始深链可能早于 `/auth/me`，总览失败也不能阻止管理员看板在身份解析后重读；保存只在返回定义与提交一致时确认成功，截断返回与排队失败保留草稿和重试。
- 从真实组装 HTML 运行行为测试，再用合成只读预览验收 1440/390、720/721 与 1100/1101 及亮暗主题。模型“半宽”应实际占二分之一；只刷新预览不会重新导入源模块，冻结自己的补丁并重启预览后再核对。

## 浏览器验收与交付

使用真实 CUA 检查桌面宽度 1440、手机宽度 390、720↔721 断点往返以及亮暗主题；验证无横向溢出和唯一导航。
走总览、告警、查询、链路、设备和低频目录；检查无权限入口、旧深链、菜单关闭与焦点恢复、图表切换后刷新、未知和失败状态。
本地预览可使用 loopback 合成 fixture，但必须标明合成数据；未实现的 API 返回明确 503，不伪造成功或称其为生产验证。
预览服务启动时导入了生成 HTML 的模块，代码组装更新后必须重启该预览进程再 reload；只刷新页面仍会拿到缓存的旧 HTML。用 normal、pending、读取失败、unknown 与异步成员身份检查实际初始请求，所有写请求在预览服务器拒绝。
CUA viewport 能力可能只改变当前可见 tab，隐藏预览 tab 仍是 1280px；每次响应式测试先从 DOM 核对实际 innerWidth。需要时用同一浏览器的可见测试 tab，结束时 reset viewport 并关闭自己的测试 tab，保留用户原有 tab。
移动端用真实点击验证底部“更多”，并读取 `elementFromPoint` 核对命中节点；固定的 AI 助手按钮应位于底部导航上方，纯文字 toast 使用 `pointer-events:none`，避免遮挡导航和误点其他工作区。
确认加载、刷新与菜单动画完成，页面状态稳定后截图；按当前 CUA 文档保存截图并使用 `markDeliverable` 标记交付。
验收结束重置 viewport，保留必要截图；报告改了什么、已运行与未运行的验证，以及合成预览的范围。
新增项目技能目录在后续会话发现；保持修改可审查，是否提交沿用当前用户授权。

## 用户授权 UI 上线时

先读 `docs/deploy.md` 与实际 `ops/deploy.sh`，再核对线上 `current` 和服务启动路径；脚本可能同时安装 Collector 配置、切 worker，不能因 UI 发布而混入这些相邻变化。
把当前源码复制到独立临时目录验证；包含 `tools/` 导入和 `ops/db-panel-allowlist.txt` 测试输入，避免因漏拷文件产生假失败。执行完整类型编译、`npm test` 与 `npm audit --omit=dev --audit-level=high`。
下载线上编译页面模块作为基线，逐文件比较构建产物；候选使用实际生产 backend/shared，加此次 UI 变化，验证依赖声明和编译页面脚本，再做启动冒烟。
源码与线上 UI 已不同步时，从真实线上 UI 做最小差分，不把本地尚未发布的正文或列表密度改造并入入口去重。源码全量回归不等价于部署候选验收：对候选实际组装的脚本验证切换、共享筛选、分页、旧深链、异步权限守卫与焦点；类型编译和无数据库候选启动另行记录，启动时明确验证业务接口因无数据库返回 503，不能据此声称生产业务通过。
保留产物清单、来源哈希与当前 release。切换前若线上 base 已变，停止切换并重新核对：已部署模块与验收版完全一致时，直接完成线上验收；不为形式再重复发布。
