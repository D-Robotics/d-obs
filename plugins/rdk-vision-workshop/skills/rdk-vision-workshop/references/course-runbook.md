# 180 分钟课程操作稿

课程来源为 [视觉 Pipeline AI Native 开发 Workshop 方案](https://horizonrobotics.feishu.cn/docx/UdhhdVXYXoPLgfxmZ32cJBSAnRb)。以下时刻以 09:30 开场为例，可按实际开场平移。

| 时间 | 学员当前一步 | 完成后留存 |
|---|---|---|
| 09:30–09:45 | 确定观察目标、区域与工位 | 一句观察目标 |
| 09:45–10:05 | 核对 X5 + IMX415，启动已适配模式 | 第一张新图、设备模式、原始 ISP |
| 10:05–10:20 | 固定场景，10:10–10:15 分别保存 RAW、ISP 显示、渲染图。10:15–10:20 分批提交 RoboGO | 三种基线图的来源、采集条件、原 Run ID 和受理回执 |
| 10:20–10:35 | 用样例辨认 Bayer RAW、ISP 显示图与渲染图 | 格式辨认记录 |
| 10:35–10:55 | 第 1 轮跟做有界 Gamma，随后第 2 轮自主 | 实际参数回读、新图、亮度对照和取舍 |
| 10:55–11:10 | 从暗部文字或整体明暗选一项，自主对照 | 观察依据与保留或恢复理由。保留原值也可完成 |
| 11:10–11:20 | 茶歇，助教核对原 Run 预计完成时间 | 原 Run 状态、超时工位的预置分支准备 |
| 11:20–11:25 | 用已有图做盲选，先写理由再揭晓 | 本人偏好和理由 |
| 11:25–11:40 | 导出选定 tuning、先恢复原值、再个人重载 | 版本身份、独立回读、重载后新图、恢复步骤 |
| 11:40–12:10 | 核对本人 Run 和预跑的 X5 产物，按 A/B/C 分流并完成相应验证 | 本人产物、预置产物或演示的来源，实际板端画面及是否检出 |
| 12:10–12:30 | 恢复原始配置、停止采集，下载并解压个人包 | 原始配置回读、手册、tuning、图像、检测记录、实际待办 |

训练默认使用组织方预置数据集、YOLOv8s、park / qrcode / obstacle 三类、640 输入、100 轮。ONNX 为 opset 11，PTQ 在 X5 Bayes-e 工具链用训练图校准并生成 NV12 制品。课堂量化尽量云端预跑，板端下发与检测按工位分批，11:30 再预检原 Run，11:40 切分流，目标单台两分钟。

- A 使用本人训练和量化产物。核对三类标签、前后处理和实际板端模型哈希。
- B 使用来源可核对的预置产物。个人训练与量化保持未完成，实机操作按实际回执记录。
- C 观看讲师演示或已有录像。记录演示来源，个人板端实操保持未完成。

照真实宿主能力调用相机、RoboGO 和板端运行工具。获取 Run 状态可以和 ISP 工序并行，继续操作时使用上一回执中的同一 Run。变化前后用可复验的图像与配置判断保留或恢复。实际 RAW 采集受阻时，分别记录讲义样例来源和本人实采缺口。开课前在冻结的 Studio 1.5.0 Windows/macOS 与同批相机模式上验证实采与交付。
