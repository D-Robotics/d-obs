# 数据库面板表白名单（生产 /etc/d-obs.env 的 RDK_DB_PANEL_TABLES 用这份内容）
#
# 为什么需要：/api/ops/observability/database* 是运营只读取证面，
# 而 d-obs 与主站共用中心库 —— 不设限时 admin token 能导出主站的商业/凭据表
# （credit_user_key、credit_account、chat_credit_accounts、redemption_code 等）。
#
# 默认行为（2026-09 起）：RDK_DB_PANEL_TABLES 未配置时，代码内置
# DEFAULT_POSTGRES_DASHBOARD_TABLES（server/monitoring/postgres-dashboard-store.ts，
# 与本文件内容一致，由 postgres-dashboard-allowlist.test.ts 双向防漂移）即本名单生效；
# 显式设 `RDK_DB_PANEL_TABLES='*'` 才恢复「整库可见」。
# 生产 env 无需再配本名单；保持配置等价于锁定当前名单（防止代码默认演进带来意外变化）。
#
# 名单怎么来的：从 server/main.ts 做一次可达性遍历（**含动态 import()**），收集可达
# 模块里所有 `from|into|update|join public.<表>` 的表名 —— 即本服务运行时真正读写的表。
# 不要手写；改了代码用测试兜底：
#   node --import tsx --test server/monitoring/postgres-dashboard-allowlist.test.ts
# 该测试会重算可达表集合并断言全部包含在本文件里，漏一张即失败（提醒同步内置名单与生产 env）。
